# C 시스템 프로그래밍 학습 기록

파일 입출력과 파일 정보 및 프로세스 제어를 C로 실습한 저장소입니다. 날짜별 강의 기록과 예제 소스를 함께 보관합니다.

## 학습 내용

| 주제 | 자료 |
| --- | --- |
| 파일 열기와 크기 확인 및 분할 컴파일 | [0402](0402) |
| 파일 복사와 레코드 생성·조회·수정 | [0409](0409) |
| 파일 속성과 권한 및 처리 시간 | [0416](0416) |
| 디렉터리 조회와 링크 처리 | [0430](0430) |
| 프로세스 생성·대기·프로그램 실행 | [0528](0528) |

전체 기록은 날짜별 폴더의 `readme.md`에서 확인할 수 있습니다.

## 예제 확인

[소스 예제](0528/ex)에는 `fork`와 `wait` 및 `exec` 계열 실습이 포함됩니다. POSIX API를 사용하는 예제는 Linux 등 해당 API를 지원하는 환경에서 확인합니다. 파일별 의존성과 입력 조건이 다르므로 저장소 전체를 단일 프로그램으로 실행하지 않습니다.

강의 예제와 학습 기록을 포함하는 기초 학습 아카이브입니다.
